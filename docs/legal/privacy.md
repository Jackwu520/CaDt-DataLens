# CaDt-DataLens 隐私协议

最后更新：2026-11-19  
适用版本：CaDt-DataLens v1.1.0

CandySweet 尊重并保护用户隐私。本协议说明 CaDt-DataLens（以下简称“本软件”）如何处理与您有关的信息。

本软件的核心原则有两条：

1. **软件自身不收集、不上传您的文件、路径与使用数据**，不包含统计、埋点、广告或崩溃上报组件，我们也没有用于接收这些数据的服务器。
2. **软件提供需要联网的可选功能**（AI 助手、AI 外部工具、检查更新、插件市场、内嵌浏览器）。这些功能只会在您主动使用、并自行配置服务商之后才联机；联机时内容由本机直接发送给您选择的服务商，不经过我们的服务器。

请特别留意第 2 节的第 2.2 款：使用 AI 助手时，**AI 读取到的文件内容会随对话一起发送给您配置的模型服务商**。

## 1. 我们收集的信息

1.1 本软件不需要注册账号，不收集姓名、手机号、邮箱、设备标识或其他可识别个人身份的信息。

1.2 本软件不包含统计、埋点、广告或崩溃上报组件，不会自动上传您的使用记录、文件内容或文件路径；本软件没有此类上传接口。

1.3 本软件的公开服务端仅为 Gitee 上的仓库（发布页、插件市场、模型配置表），由其承载方按各自的隐私政策处理访问日志；我们不在其中设置任何用户级追踪。

1.4 您通过“反馈”入口主动打开 Gitee 问题页面时，您在页面上提交的内容由您自行决定，并受 Gitee 的隐私政策约束。

## 2. AI 助手与第三方服务

2.1 **本软件不内置任何 AI 服务商、不内置任何密钥。** AI 助手、生图与视频、联网检索、OCR、语音合成与识别等功能，只有在您于“设置 → AI 助手 / 外部工具”中自行填写服务商地址与密钥、或绑定本地 MCP 服务后才可用；您也可以随时关闭这些功能与能力来源。

2.2 **使用 AI 对话时发送的内容。** 本软件把对话请求直接发送给您配置的模型服务商（OpenAI 兼容、Anthropic 或 Responses 协议端点）。该请求包含：

- 您输入的文字与附加的图片；
- AI 通过工具读取到的内容，包括您让它读取的**文件正文、目录列表、搜索结果、命令与终端输出、网页正文与图片**，以及被引用的历史会话与工作区记忆；
- 系统提示词与运行上下文，包括**工作区路径与名称、工作区守则、权限档、工具清单、当前时间**等；
- 已授权的审批对象（当您批准某项写操作或命令时，该操作的参数与摘要）。

因此：**您在 AI 对话中让 AI 读取的任何内容都可能离开本机并留在服务商处。** 请不要把不允许外发的资料（含密钥、客户数据、涉密文档）交给 AI 读取；需要在本机处理时，关闭 AI 功能或仅使用不读取内容的本地工具。

2.3 **AI 外部工具与生成服务**按您在设置中选择的能力来源处理：

- 联网搜索、网页抓取、图片抓取：走软件内置的检索通道（Bing 检索结果、公网页面抓取）或您配置的服务提供商；
- OCR、语音合成（TTS）、语音识别（ASR）、生图与视频生成：把您提供的图片、音频、文本或提示词发送给您选择的服务提供商；
- AI 账号余额 / 用量查询：携带您的密钥直接请求对应服务商的官方接口；
- 本地 MCP 来源：脚本在您的机器上运行，不联网即全部离线（内置示例中的 SAPI 语音合成、Windows OCR、whisper 语音识别均为本地实现）。

2.4 **模型配置表**：启动与手动刷新时，从公开地址（默认 Gitee 上的 `model-catalog` 仓库）获取公开的模型清单 JSON，请求不包含您的文件、密钥或个人信息。

2.5 **MCP 服务器**：MCP 服务器由您自行配置（本地命令或远程地址），其网络访问与数据处理行为由该服务器负责。请只安装您信任的服务器，并留意其为 AI 提供的工具能力。

2.6 **密钥的使用与保存**：您填写的 API Key 只用于本机向对应服务商发起的请求，我们无法获取。密钥随账号配置保存在本机应用数据目录的 `ai-config.json` 中（另有一份界面本地存储镜像），文件权限仅限当前 Windows 用户——与多数本地开发工具的做法一致，本软件不对其额外加密，依靠系统账户保护（详见第 6.1 款）；如希望借助系统加密保存，请改用“环境变量”功能登记，其值以 Windows DPAPI 加密。

2.7 **端侧命令分类器完全离线**：内置线性模型与语义插件均在本机推理，不上传命令文本；个性化学习样本也只保存在本机。若您开启“远程 AI 分类器”复核，命令文本会随复核请求发送给您配置的模型服务商。

2.8 请求内容在服务商侧的留存、用于训练与否、再次分发，均适用对应服务商的隐私政策与条款；相关费用也由您与服务商结算。请在启用前阅读该服务商的条款。

## 3. 本地数据

3.1 本软件在本机保存以下数据，均不会自动上传：

- **界面设置与状态**（主题、字体、布局、视图偏好、草稿、未读标记等）保存在 WebView2 本地存储中；
- **后端配置** `config.json`（打开方式、插件目录模式、开发者模式等）；
- **AI 配置** `ai-config.json`：模型账号（含 API Key）、提示词、偏好、审批白名单；同一份内容另有一份界面本地存储镜像；
- **环境变量** `env-vars.json`：默认以 Windows DPAPI 加密，仅当前 Windows 用户可解密，注入到内置终端与命令桥子进程；
- **AI 会话记录** `ai-sessions/`（按工作区分目录）、**群聊记录** `ai-groups/`、**会话搜索索引** `ai-index.db`（派生索引，删除后可重建，不影响会话正文）、**定时任务** `ai-schedule.db`；
- **操作记录** `activity/`（按月追加的 JSONL，只存操作摘要，不含文件正文与密钥）；
- **端侧分类器的个性化样本** `local-classifier/`（命令文本打码后保存，可随时清空）；
- **快捷便签** `memo/`（含您粘贴的图片）；
- **工作区破坏防护备份** `wipe-guard/`：**包含被 AI 覆盖或删除文件的完整内容副本与定期的状态快照**，用于事后恢复；
- **内嵌浏览器的实例数据**：每个 AI 会话使用独立的浏览器配置目录，其中含 **Cookie、缓存与登录状态**；
- **运行日志** `logs/`、插件、内置技能与内置 MCP 示例的释放副本、模型配置表缓存。

3.2 **工作区内的数据。** 部分功能会把数据写进您当前工作区的 `.cadt/` 目录：AI 工作日志（`logs/`）、工作区便签（`memo/`）、工作区记忆（`memory/`）、计划模式正文（`plan/`）、补丁库与原始字节备份（`patches/`）、生图与视频产物（`gen/`）、AI 回答页面（`answers/`）、临时文件（`tmp/`）、隔离草稿区（`worktree/`）。这些文件属于工作区文件的一部分，**若您把工作区提交或分享给他人，其中内容也会一并被提交或分享**，请注意甄别。

3.3 **日志内容。** 错误与警告日志可能包含出错的本地文件路径、错误文本与程序版本信息；开发者模式会额外记录调试信息。当 AI 请求被服务商以参数等错误拒绝时，本软件会把该次**完整请求体**（含对话内容与工具清单，不含 API Key）转存到 `logs/` 目录，用于排查问题。以上内容均只保存在本机。

3.4 应用数据默认位于：`%APPDATA%\CandySweet\CaDt-DataLens`。日志仅保留最近若干次运行，其余本地数据的保留时长由您自行管理。

3.5 本软件不会把您的文件、配置或会话备份至云端。

3.6 卸载本软件不会自动删除应用数据目录，也不会删除工作区内的 `.cadt/` 目录。如需彻底清理，请在卸载后手动删除应用数据目录；工作区内的数据请自行清理。

## 4. 网络请求一览

本软件仅在以下功能被您主动使用时发起网络请求：

| 功能 | 访问对象 | 发送内容 |
| --- | --- | --- |
| 检查更新 | Gitee API | 程序名称与版本号 |
| 插件市场 / 更新插件 | Gitee API | 无个人信息 |
| 从仓库安装插件 | 您指定的 Git 仓库 | 建立连接所需的信息 |
| 获取模型配置表 | 公开地址（默认 Gitee） | 无个人信息 |
| AI 对话、AI 分类器复核 | 您配置的模型服务商 | 见第 2.2 款 |
| AI 外部工具、生图与视频、余额查询 | 您配置的服务提供商或内置检索通道 | 见第 2.3 款 |
| MCP 服务器 | 您配置的本地脚本或远程地址 | 由其自身实现决定 |
| 内嵌浏览器 | 您访问的网站 | 常规浏览器请求（含 Cookie） |
| Markdown 预览 | 文档中的外链资源所在站点 | 预览时由界面引擎直接加载 |
| 打开外链 | 系统默认浏览器 | 交由系统处理 |
| 内置终端、运行代码、插件 | 由其运行的程序自身决定 | 不受本协议控制 |

上述请求会向对端传输建立连接与完成请求所必需的信息（如 IP 地址、User-Agent、Cookie），其处理方式适用对应服务提供方的隐私政策。

## 5. 第三方插件与 MCP 服务器

5.1 第三方插件与 MCP 服务器可能拥有独立的网络访问、文件访问或数据收集行为，这类行为由插件作者或服务器提供方负责，不在本协议的控制范围内。

5.2 插件代码在本软件界面内运行，可以扩展命令、格式、主题与命令分类器，并可能为 AI 注册工具能力；请仅安装来源可信的插件。您可以在插件目录中查看、禁用或删除插件。

## 6. 数据安全与保留

6.1 **本机数据的保护依赖您的系统账户。** 应用数据目录由当前 Windows 用户私有；除 `env-vars.json`（以 Windows DPAPI 加密）外，本软件不对单个文件额外加密——服务商密钥保存在本机配置文件中，仅受系统账户权限保护，这与多数本地开发、命令行与 AI 工具的做法一致。请为 Windows 账户设置登录口令，并避免在共享计算机上保存密钥。

6.2 **工作区破坏防护备份包含您文件的完整副本**，位于应用数据目录内（可自定义到其他磁盘，但不允许指向工作区内部），并对其套用禁止删除的访问控制，以降低备份被同一批命令一并删除的风险。该备份可在“设置 → 存储与清理”中查看与清理。

6.3 您可以在“设置 → 存储与清理”中查看占用、清理缓存、按项删除本地数据，或配置自动清理；删除前请确认对应数据不再需要（会话记录、操作记录、备份等删除后不可恢复）。

6.4 数据的保存位置与保留时长由您自行管理；我们无法访问、也不保留您的任何本机数据。

## 7. 未成年人保护

本软件是本地数据查看与编辑工具，不面向未成年人收集任何个人信息。未成年人应在监护人指导下使用；涉及 AI 功能与外部服务（可能产生费用、需要向第三方发送内容）时，应由监护人决定是否启用。

## 8. 协议更新

我们可能随软件版本更新调整本协议。更新后的协议将通过软件内文档或发布页面提供，自发布之日起生效。若新版本引入了新的联网功能或新的数据类型，我们会在更新说明中注明。
