## 五、失败怎么记

按「编号 / 现象 / 复现步骤 / ⑤⑥ 里的关键行」四段记录，并优先对照原计划 §6 的三张排查表
（压缩中不动 → 路由顺序；派单后主代理不动 → `finalizeSubAgent` resolve；通知到了下一轮看不到 → 消费点）。
